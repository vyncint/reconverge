# RC004 — static shared memory exceeds the target's limit

The kernel's statically declared shared memory (`SharedArray`, `Barrier`,
…) adds up to more than the static per-block cap, or more than the target
compute capability can physically provide.

## A minimal failing kernel

```rust
#[kernel]
pub fn over_budget(mut out: DisjointSlice<f32>) {
    // 16384 * 4 bytes = 65536 bytes — over the 49152-byte static cap
    static mut TILE: SharedArray<f32, 16384> = SharedArray::UNINIT;
    // …
}
```

`SharedArray<T, N>` occupies `N * size_of::<T>()` bytes of shared memory on
the device (the host-side value is only a marker); a `Barrier` occupies 8
bytes. RC004 sums every shared static the kernel can reach.

## What happens on hardware

Shared memory is a fixed physical resource per streaming multiprocessor,
and the static allocation limit is 48 KiB (49152 bytes) regardless of
target; anything above that requires the dynamic allocation path with an
explicit opt-in. A kernel over the limit does not fail at build time — it
fails at *load or launch time* on the machine that runs it, with an error
the person who wrote the kernel may never see. With `--cc <X.Y>` the
diagnostic also reports the chosen target's total per-block capacity, since
what fits on one compute capability may not fit on another.

## The fix

Shrink the tile, split the work into passes, or share one buffer between
phases separated by `sync_threads()`:

```rust
// 12288 * 4 bytes = 49152 bytes — exactly at the static cap
static mut TILE: SharedArray<f32, 12288> = SharedArray::UNINIT;
```

If the algorithm genuinely needs more, use the dynamic shared-memory path
with its explicit capacity opt-in rather than a larger static.

## Notes

- Reported at `deny` confidence: the sizes are compile-time constants; no
  divergence analysis is involved.
- Pass `--cc <X.Y>` (e.g. `--cc 8.6`) to check against a specific target's
  capacity table and get capacity context in the message.
- SIMT fundamentals: `cargo reconverge learn` ships four interactive
  lessons (divergence, barriers, masks, reconvergence), fully offline.

# RC001 — `sync_threads()` under thread-divergent control

A block-wide barrier is reachable on a path that only *some* threads of the
block take. Threads that never reach the barrier never arrive at it, and the
threads that did reach it wait for them.

## A minimal failing kernel

```rust
#[kernel]
pub fn divergent_barrier(mut out: DisjointSlice<u32>) {
    let i = thread::index_1d();
    if i.get() % 2 == 0 {
        thread::sync_threads(); // RC001: only even threads arrive
    }
    if let Some(e) = out.get_mut(i) {
        *e = 1;
    }
}
```

The branch condition depends on `i`, a per-thread value: even-numbered
threads enter the `if` and arrive at the barrier; odd-numbered threads skip
it entirely.

## What happens on hardware

`sync_threads()` compiles to a barrier that waits until **every thread of
the block** arrives. When a thread's path never reaches the barrier, the
arrival count stays short forever. There is no error, no log line, and no
recovery: the block simply stops making progress — on most configurations a
permanent hang until an external watchdog kills the kernel. This is
undefined behavior, and it usually hangs; a run that happens to finish is
luck, not correctness.

Note that threads of a warp do not execute in guaranteed step with each
other (independent thread scheduling, since compute capability 7.0), so you
cannot reason your way out of this with "the warp executes both sides
anyway". The barrier contract is per *thread*, and every thread must reach
it.

## The fix

Reconverge first, then synchronize. Move the barrier out of the divergent
branch so every thread executes it:

```rust
#[kernel]
pub fn convergent_barrier(mut out: DisjointSlice<u32>) {
    let i = thread::index_1d();
    if i.get() % 2 == 0 {
        // divergent work, no barrier
    }
    thread::sync_threads(); // every thread arrives
    if let Some(e) = out.get_mut(i) {
        *e = 1;
    }
}
```

A barrier under a **block-uniform** condition is fine, because the whole
block takes the same side of the branch:

```rust
if thread::blockIdx_x() > 3 {
    thread::sync_threads(); // OK: every thread of a block agrees
}
```

Kernel parameters, `block_idx`-derived expressions, and constants are
block-uniform; thread indices, lane ids, loads from thread-dependent
addresses, and atomic return values are not.

## Notes

- Reported as `confirmed` when the witness interpreter replayed a concrete
  hang (the diagnostic then shows the launch configuration and a lane
  diagram); as `warning` when the divergence is conservative static
  reasoning only (shown with `--strict`).
- The provenance chain in the diagnostic walks the branch condition back to
  its divergence source, hop by hop; `cargo reconverge inspect` navigates
  the same chain interactively.
- Lesson: `cargo reconverge learn` — lesson 2 (*barriers*) replays this
  exact hang lane by lane, and lesson 4 (*reconvergence*) is the fix.
